# Claims register

One row per atomic claim that is a number, a mechanism, a mapping, or appears in more
than one file. The **Claim** column holds the canonical wording; other files summarize
and link. Current claims only: superseded wording lives in [decisions.md](decisions.md).

Status is one of: **verified** (source quoted), **observed** (evidence, no cause),
**unverified** (must be labelled as such in the text), **analyst reading** (e.g. T1133).
